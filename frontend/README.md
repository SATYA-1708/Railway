# RailFlow AI Frontend

React/TypeScript and Vite interface for RailFlow AI. The application includes passenger and operations views, map/chart dependencies, and backend API access.

From this directory, install with `npm ci` and start with `npm run dev`. Available package scripts also include `build`, `lint`, `test`, and `preview`. Configure the API base URL for the local Python backend. See the repository-level [`README`](../README.md) for system architecture and backend configuration.
